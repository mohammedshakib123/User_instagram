# 3D Holographic Smart Card Profile - Mohammed Shakib

A futuristic 3D Holographic Instagram Profile & Connect Hub built with HTML5, CSS3, and JavaScript.

## Features
- **3D Tilt & Gyroscope Physics**: Interactive 3D perspective effect with glassmorphism and holographic scanlines.
- **Scannable Dynamic QR Code**: Flip card to reveal an instant follow QR code.
- **Customization & Sound FX**: Editable text fields and interactive audio feedback.
- **Direct Connect Hub**: Quick links to Instagram, WhatsApp, and DM.
- **Photo Gallery & Highlights**: Instagram-style story moments and featured photos.

## Tech Stack
- HTML5
- CSS3 (Custom Glassmorphism, Animations, Flexbox/Grid)
- JavaScript (ES6+, QR Code generation, Canvas/HTML2Canvas export)
- FontAwesome Icons & Google Fonts (Syne, Plus Jakarta Sans, Outfit)

## Live Preview
Open `index.html` in any modern web browser or host on GitHub Pages.
